# 任务 11.2b：四人声音定点返工（负责：sol；Fable 验收）

## 背景

11.2 已合进集成分支 `phase-11`（817a449），新闻卡、事件密度和经济部分都已验收。只有人物声音没达标。

### 盲测结果

Fable 做了两轮独立盲测，方法与 11.1b 相同：
- 每人每轮抽 5 句，两轮的句子互不重复。
- 答题的子代理只看到 12 个人名和一句身份。

两轮合计命中 **81/120 = 67.5%**，目标是 ≥ 75%。分人如下：

| 人物 | 两轮合计 |
|---|---|
| 拉赫曼、加雷思 | 10/10 |
| 玛格丽特 | 9/10 |
| 海伦、戴夫、陈乐言 | 8/10 |
| 阿德 | 7/10 |
| 周沅 | 6/10 |
| **杰米** | **5/10** |
| **普里娅** | **4/10** |
| **莉娜** | **3/10** |
| **许文舒** | **3/10** |

其余 8 人已经稳定，这一轮**只改莉娜、许文舒、普里娅、杰米**。

### 错判去向

- **莉娜**：被认成周沅 4 次，认成陈乐言、普里娅各 2 次。
  - 她 115 句里 60 句在讲画画。画纸、颜料、留白，跟装裱员周沅撞题；满屏感叹号又跟孩子撞调。
  - 她的身份是"正在为拒签找办法的朋友"，台词里却几乎看不到拒签、补材料、上诉、Plan B 这条线。
  - 11.2 把"喂／拜托／烦"从 70% 砍到 23%，砍过头了。
- **许文舒 ↔ 杰米**：
  - 文舒被认成杰米 3 次、莉娜 2 次；杰米被认成文舒 4 次。
  - 两人都是伴侣，都在谈家务分工、庆祝、谁拿什么。
  - 文舒的"X 还是 Y？"结尾杰米也会用，比如"我拿盘子你拿茶？"。
  - 文舒的"讲好先"是好特征，但出现太少。
- **普里娅**：拼图 25 句、电话／耳机 34 句。可拼图句被认成杰米、莉娜，因为盲测只知道她是"GP 诊所前台"，拼图对不上身份。接待台的流程用语（核对、预约、"先坐这边"）出现不够。

## 要做的

1. **身份线索**：这四人每人至少一半常规台词，要能从说话内容或用词对上身份一栏。
   - **莉娜**：拒签后的处境，比如材料、截止日、找律师或慈善机构、Plan B、等回信的火气。她的画画降为次要话题，并且避开纸张、装裱、胶这类周沅的词。可以恢复带火气的口头禅，频度 30–45%。
   - **普里娅**：接待台工作。核对、预约、排队、"请先……"这类前台句式。拼图和耳机保留为生活细节。
   - **许文舒、杰米**：两人都谈家里事，但要一眼分开：
     - **文舒**："讲好先"这类先立约定的说法，加上二选一问句，两者至少一半句子出现其一。少用感叹号。
     - **杰米**：不再用二选一问句。保留"咱们"、感叹号和自嘲。给他一个文舒没有的固定话题，比如足球、做饭翻车、迷路的近路，频度 25–40%。
2. **只改这四人**：
   - 改动包括他们的常规台词，以及他们好感剧情里的引语。
   - 其他 8 人的台词不动。
   - 风格指南里只更新这四人的条目。
3. **自测**：用与 Fable 不同的种子自测一轮，把四人的标志词频度写进报告。Fable 会另换种子做两轮独立盲测。目标：合计 ≥ 75%，单人两轮合计 ≥ 5/10。
