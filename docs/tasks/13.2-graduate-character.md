# 任务 13.2：第四位角色——毕业生转 Skilled Worker（负责：sol；Fable 验收）

## 背景

12.0a 调研 E7（`docs/research/2026-11-15-policy-update.md` §6）建议做一个 Graduate 路线的人物。12.2 已登记以下来源：
- SRC-034：Appendix Graduate，GR 8.1 的时长表；
- SRC-035：Appendix High Potential Individual；
- SRC-036：HPI 大学名单。

引擎已有 `GRADUATE`、`HIGH_POTENTIAL_INDIVIDUAL` 路线：两者在 Skilled Worker 定居中为 `NOT_COUNTING`；Long Residence（LR 11.1）把它们算作连续合法居留。现有三位角色是林遥（Skilled Worker）、陈嘉宁（BN(O)）、索菲娅（伴侣）。

## 要做的

1. **人物**：一位刚在英国读完硕士的毕业生，国籍、姓名、专业、性格自定。
   - 必须是虚构人物，遵守 `style-guide.md`，有自己的声音，与现有 12 人区分得开。
   - 开局持有 Graduate 许可。按 SRC-034 GR 8.1 的申请日分界确定时长：在 2027-01-01 之前申请、非博士，为 2 年。开局日期和申请日自定，但要能追溯到这条规则。
2. **主线压力**：
   - 在 Graduate 许可到期前，找到有担保的工作，并在签证中心转为 Skilled Worker；
   - 转换后的许可、薪资和定居评估都交给引擎，不在游戏里自算；
   - 转不成功就逾期出局，或者离开英国。
   - 求职过程用事件链来写：投简历、面试、HR 发 CoS、薪资是否达标。Skilled Worker 的薪资门槛只能读 `policy-data` 的现有参数，不得硬编码。
3. **内容量**：
   - 专属普通事件卡 ≥ 60 张，覆盖求职、毕业后的同学离散、搬出学生宿舍、第一份工作；
   - 一位专属家人或室友 NPC，带台词和 5 段好感剧情；
   - 开局卡与定居结尾各一段。
   - 体量与平衡断言要扩展到第四位角色：逐局汉字 ≥ 15,000，台词不重复率 ≥ 80%，以及随意、积极策略的好感剧情数量。
4. **政策文本**：所有日期和年限都在代码注释里带 `SRC-xxx` 定位。政府未定的细节（例如预算案提到的部分大学两年 Graduate）写成"待细则"，或者不写。

## 约束

- 改 `packages/game/**`；如果确实需要新的有来源参数（例如 Graduate 时长），可以改 `packages/policy-data`，参数要带 SRC 定位与测试。尽量不改 `packages/engine`；如果必须改，在报告里说明原因和所引的规则条款。
- 公开 API 的现有名字和形状不变。新角色 ID 会进入角色列表，客户端选人页应能自动显示它；如果客户端写死了三个角色，在报告里列出位置，留给 astra 处理。
- 测试：
  - 新角色的开局、Graduate 到期、成功转工签、逾期出局；
  - 引擎对 Graduate 加 Skilled Worker 时间线的评估结果；
  - 体量与平衡；
  - 已有全部测试通过。
- 验收命令：`pnpm lint && pnpm typecheck && pnpm test && pnpm build`，退出码须为 0。
- 不 commit，报告里按"应当成为的 commit"分组。不要过度工程化。
