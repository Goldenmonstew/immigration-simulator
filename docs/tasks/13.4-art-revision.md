# 任务 13.4：按 agy 第三轮评审返修美术（负责：astra；13.3 之后；Fable 验收）

## 背景

agy 第三轮评审（`docs/research/2026-11-16-design-review-3.md`）给 13.1 的原创美术打出 7.9 分。主要问题是立绘共用一套脸型模板，有几组撞脸，且与设定不符。§一.6 给了逐文件的修改清单。

## 要做的

按评审 §一.3–§一.6 逐项修改：

1. **拉开撞脸组**，同步改对应的行走图 `urban/*.png`，让行走图与立绘一致：
   - 普里娅、莉娜、周沅：发色、发型、肤色要彻底分开；
   - 海伦、许文舒、索菲娅：只有索菲娅保留深肤卷发；海伦、许文舒按评审建议改；
   - 阿德与加雷思：帽子不同；去掉阿德额头上那条黑杠；
   - 嘉宁与玛格丽特：衣色和发色要拉开；拉赫曼要和戴夫、林遥区分开；
   - 戴夫：与光头的行走图一致，补上轮廓缺口。
2. **陈乐言**：改成孩童体态，肩更低更窄、下巴更圆、眼睛更大。
3. **表情细节**：
   - 胡子不压牙；
   - 担忧时的眉毛不插进帽檐，也不隐没在发色里；
   - 戴眼镜的人笑起来眼睛留出空隙；
   - 诺拉担忧时的嘴要清楚。
4. **诺拉、梅芙**：与其他 15 人统一轮廓粗细与比例；三种表情以 neutral 为底只改五官，消除整图的色偏；清理杂点。
5. **横幅与招牌**：
   - 横幅：太阳往下移并修圆，行人更清楚；
   - 招牌：语言学校、市政厅、签证中心三块按评审改；
   - 招牌位置避开屋瓦和二层窗。
6. **尺寸**：头像统一为整数倍缩放，例如 64×64 或 96×96，手机上 64×64；首页横幅裁切不切掉太阳和小河。
7. **人物设定一致**：立绘与行走图的外观，要与 `packages/game` 中各人的身份和背景相符。只读这些设定，不改它们。

## 约束

- 只改 `apps/web/**`，外加报告 `docs/tasks/reports/13.4-art-revision.md`。所有素材都是原创 CC0，更新 `ATTRIBUTION.md`。
- 测试：已有的美术完整性测试与 web 测试全部通过；加一条测试，确认 17 人的 neutral 立绘两两之间不完全相同，比较像素哈希即可。
- 验收命令：`pnpm lint && pnpm typecheck && pnpm test && pnpm build`，退出码须为 0。
- 你不能用浏览器。报告里放一张前后对照清单，写明每个文件改了什么。
- 不 commit，报告里按"应当成为的 commit"分组。
