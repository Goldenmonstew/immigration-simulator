# 任务 40 与 50 的诺拉部分

由 Fable 实现（2026-11-20 起开发由 Fable 负责，Codex 只读审核）。两项同改诺拉的游戏文件，按计划顺序在 35 之后合并为一个分支。

- **40**：诺拉情景补两处说明：递交与获批的先后及 section 3C 延续（SRC-055）；符合条件的 Student 可直接在境内转 Skilled Worker（SRC-004 SW 1.5A），新入职者档资格看 SW 12.2(e)。
- **50 诺拉部分**（Codex 试玩 #7–#9 与 P2 的低严重度项）：求职进度与下一步；签证中心核对先写两档结论；快进会跨过许可到期时写明日期并给"去签证中心"；转签后到期的结局不再提 Graduate 转签；转签后不再出现求职类生活卡。
