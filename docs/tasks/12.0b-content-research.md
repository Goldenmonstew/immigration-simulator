# 任务 12.0b：内容盘点与玩法调研（负责：astra；Fable 验收）

## 目标

全面盘点游戏《移民生活》现有内容，对照同类生活模拟游戏和真实的在英移民生活，找出内容最薄、最值得扩展的地方，给出带优先级的扩展清单。只调研、只写报告，不改代码。

## 要读的现状

- `docs/tasks/phase-8-plan.md`、`phase-9-plan.md`、`phase-10.5-plan.md`、`phase-11-plan.md`：方向与已知缺口。
- `packages/game/src/`：
  - 人物、台词、好感剧情；
  - 事件卡（`characters/`、`events/`）；
  - 地点与行动（`locations.ts`）；
  - 节日、物品、钓鱼、菜地、厨房；
  - 结局；
  - 平衡参数 `balance.ts`；
  - 风格指南 `style-guide.md`。
- `apps/web/app/game/` 与 `apps/web/public/game/`：小镇地图、美术素材、界面、音效。
- 用户的方向偏好：
  - 要的是生动的生活模拟（参考模拟人生、星露谷物语、寒霜启示录）；
  - 不要政策卡牌游戏；
  - 季度当章节，天当玩法。

## 要做的

1. **内容盘点**：数字以代码为准，最好用一次性脚本或测试统计，统计方法写进报告。
   - 三个角色各有多少：事件卡（按渠道、季节、触发条件分）、好感剧情、台词、地点、行动、物品、节日活动、结局变体。
   - 一局十年里，玩家实际能见到多少不同内容，重复率多高。可参考 `packages/game/test/balance.test.ts` 的统计。
   - 美术与音效：用了哪些素材包；哪些地点、物件、人物只有占位或标签；有没有动画和环境音。
2. **同类游戏调研**：星露谷物语、动物森友会、模拟人生、Spiritfarer、A Short Hike、Unpacking 等。
   - 要看的方面：
     - 日常循环；
     - 收集与长期目标；
     - 人物关系深度；
     - 季节与节日；
     - 家与装饰；
     - 小游戏；
     - 惊喜事件；
     - 结局与成就。
   - 每个方面先说它们怎么做，再说我们缺什么。
   - 来源用官方页面、开发者访谈、可靠评测或 wiki，并注明出处。
3. **真实移民生活素材调研**：在英新移民的真实日常，例如：
   - 落地手续：开银行户口、注册 GP、National Insurance number、council tax、租房的 Right to Rent、eVisa 账户；
   - 生活与社区：天气与季节、社区活动、宗教与节日、孤独与思乡、工作文化、孩子上学、带父母探亲。
   - 优先用 gov.uk、NHS、Citizens Advice、ONS 和慈善机构的指南；个人经历类来源只能用于提供氛围，并要注明。
   - 这些素材要能转成事件卡、人物处境或地点。
4. **试玩问题回顾**：汇总历次试玩与验收中提到、尚未处理的问题。来源是各阶段计划的"不做"一节，以及 `docs/tasks/reports/` 里的发现与建议。

## 产出

写入 `docs/research/2026-11-15-content-expansion.md`：

1. **现状盘点**：给出表格和统计方法。
2. **同类游戏对照**：按上面列出的各方面逐一对照。
3. **真实生活素材库**：每条写一句素材、来源，以及可落地的形式（事件 / 人物 / 地点 / 活动）。
4. **扩展清单**：
   - 带优先级，P0 / P1 / P2；
   - 每项写明负责 package（game 归 sol，web 与美术归 astra）、粗略规模、依赖与风险、验收方式；
   - 每项尽量写成能直接变成任务 brief 的粒度。
5. **未处理的试玩问题**：列成清单，并给出处理建议。
