# 任务 12.4：有来源的政策生活事件与镇民作息（负责：sol；Fable 验收）

## 背景

12.0a 调研（`docs/research/2026-11-15-policy-update.md` §6 E3–E5、§5 D7–D9）建议了一些既真实、又不必猜测未公布细则的生活内容。12.2 已把相关来源正式登记为 SRC-032–048，见 `docs/SOURCES.md`，以及报告 `docs/tasks/reports/12.2-sources-refresh.md`。

另外，Fable 在浏览器里发现：清晨和傍晚 8 位镇民的作息都落在 `home-street`，全挤在你家门口（`packages/game/src/npcs.ts` 的作息表）。

## 要做的

1. **预算案新闻与"等细则"**（E3）：
   - 一张按日期出现的新闻卡：2026-10-28 预算案，依据 SRC-032 的确切小节。写法沿用 `events/policy.ts`。
   - 只说方向和实施窗口，不给任何新金额，也不说已经生效。
   - 之后按角色各来一张不同的后续卡，因为三人处境不同，不能共用一句"定居翻倍"之类的话（见 D8、D9）：
     - 林遥：HR 来信核对岗位与工资材料，参考 SRC-033 的书面答复；
     - 嘉宁：BN(O) 路线不在这次框架内，写同事或邻居问起时的反应；
     - 索菲娅：写英国公民伴侣家庭的处境。
   - 政策后果仍然只由引擎计算，卡片选择不改变任何资格结果。
2. **eVisa 与来访家人**（E4）：
   - 一条换护照后更新 UKVI 账户、出行前核对的生活小链，依据 SRC-042。不能把更新账户写成续签或获批。
   - 一条家人来访的准备链：准备客房、接站、一起做饭、送别。
   - 来访者需要 ETA 还是签证，按国籍区分，依据 SRC-043。只写人物正在核对、准备，不判定能否获批。
3. **收入中断与家庭不同步**（E5）：照护家人、病假、伴侣换班这类处境，各角色至少一条。复用现有的收入、家庭事实与事件机制。用了合法支持，不能写成道德惩罚；未定的豁免不能写成承诺。
4. **镇民作息分散**：
   - 让 8 位镇民清晨和傍晚分散在小镇不同地方，比如各自的家门口、店里、长椅、池塘边，不再全挤在你家门口。
   - 只改作息表的数据。如果需要新的地点锚点，在报告里写清楚锚点名和用途；客户端已经按锚点寻路，astra 第二波会补画面。

## 约束

- 任何政策数字或日期都要带 `SRC-xxx` 定位，写在代码注释里，按 `events/policy.ts` 的现有惯例。不确定的写"待细则"，不写数字。
- 文案遵守 `style-guide.md`：中英同步，旁白用"你"。
- 只改 `packages/game/**`，外加报告 `docs/tasks/reports/12.4-policy-life-events.md`。公开 API 的名字与形状不变。
- 测试：
  - 新闻窗口外不出现，只出现一次；
  - 后续卡按角色隔离；
  - eVisa 链与来访链的前置条件与存读档；
  - 作息分散：任意时刻同一锚点上的镇民不超过 2 人，节日除外。
  - 已有体量、平衡、好感剧情断言照旧要过；快进每年事件数不能下降。
- 验收命令：`pnpm lint && pnpm typecheck && pnpm test && pnpm build`，退出码须为 0。
- 不 commit，报告里按"应当成为的 commit"分组。不要过度工程化。
