# 任务 12.6：三角色生活链、生活记录数据与公共花坛（负责：sol；Fable 验收）

## 背景

12.0b 调研（`docs/research/2026-11-15-content-expansion.md` §3、§4 E04／E05／E07）建议：先把生活经历留下持续的痕迹，再增加内容总量。

12.5 的发现（`docs/tasks/reports/12.5-lunch-scene-and-ending.md` §4）：
- `GameState` 没有做菜的持久历史，结局无法回收"做过的菜"；
- 收获日志只记双语作物名，没有物品 ID。

## 要做的

1. **生活记录数据（E04a + 12.5 发现）**：给 `GameState` 增加最小的持久记录。
   - 首次钓到的每种鱼、首次做成的每道菜、每次收获的作物，都按物品 ID 记录，附带年与季。
   - 吃掉或送出之后记录仍在。
   - 旧存档读入时，记录为空也要能正常运行；如果需要升级存档版本，按现有惯例处理。
   - 在报告里写清楚字段契约，供 astra 做收藏册界面和结局"做过的菜"。
2. **三角色生活链（E07）**：
   - 每个角色一条，每条 3–4 场，有前因、有回访：
     - **林遥**：新工作的共同午餐，或邻居搬家；
     - **嘉宁**：校服交换桌与家长网络；
     - **索菲娅**：与杰米的共同账本，或亲友来访的家务分工。
   - 素材取调研报告 §3 的 L 库，并复用现有相关卡，不要重复已有的电表、鞋子、账单卡。
   - 每条有两种合理的选择，两种都不道德化，也不强迫选高花费的那一种。
3. **公共花坛项目（E05a）**：
   - 一条跨季度的公共项目：社区菜地边的公共花坛，分 3 个阶段，共 4–6 场互动，涉及 2 位现有 NPC（例如玛格丽特，再加一位）。
   - 两种参与方式都能推进，例如出力，或捐出自己种的苗；没钱也能参与。
   - 快进不会自动完成。
   - 每个阶段的状态写进契约，供 astra 画出各阶段的变化。
