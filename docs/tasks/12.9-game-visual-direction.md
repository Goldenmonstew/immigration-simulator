# 任务 12.9：游戏界面"暖木与草甸"换肤与手机布局（负责：astra；12.8 之后；Fable 验收）

## 背景

agy（Gemini）的设计评审（`docs/research/2026-11-15-design-review.md`）指出，影响最大的问题是：游戏浮层沿用网站的政务蓝样式，与像素风小镇严重割裂（§四 P1）。评审还提了"暖木与草甸"统一视觉方向（§五），以及手机端顶栏和 HUD 吃掉半屏的问题（P4、P9）。本任务在 12.8 之后进行。

## 要做的

1. **游戏主题变量**：在 `/game` 范围内用 CSS 变量建立评审 §五 的色板，包括背景、弹窗底、边框、主次按钮、HUD、属性条五色、红心色。
   - 网站其他页面（问卷、结果、政策、说明）保持现有的政务风格，不受影响。
   - 对比度要符合 WCAG AA，正文 ≥ 4.5:1，在报告里列出关键配色组合的实测对比度。
2. **面板与按钮家族**：
   - 早晨卡、事件卡、地点菜单、对话框、季度小结、背包、商店、结局，统一使用评审 §五.3–5 的面板、按钮和选项卡片样式；
   - 取消政务问卷式的左蓝条选项；
   - 触控控件 ≥ 44×44px。
3. **对话框**：按评审 §五.5 改成"铭牌 + 头像 + 台词 + 底部按钮"的布局。点台词区可以跳过打字机效果。
4. **HUD**：
   - 桌面：按 §五.6 两排、不折行；
   - 手机：一行时间与核心按钮、一行紧凑属性；
   - 手机端 `/game` 的网站顶栏收成一行。
   - 375×812 下首屏要能看到画布，并能直接到达地点入口：用底部 Dock 或可展开的地点抽屉，具体自定。
5. **选人页**（P9）：
   - 三张卡在桌面上一行对齐，按钮底部对齐；
   - 标题用中文游戏名加英文副标题；
   - 头像加像素相框。

## 约束

- 只改 `apps/web/**`，外加报告 `docs/tasks/reports/12.9-game-visual-direction.md`。不改 `packages/game`。
- 不引入新的字体文件或 UI 库。图标优先复用 `public/game/assets` 里已有的素材；需要新素材时只用 CC0，并更新 `ATTRIBUTION.md`。
- 不改游戏逻辑和文案含义；只改样式、布局，以及评审点名的少量界面文案。
- 测试：已有 web 测试全部通过；为手机布局切换、主题作用域补必要的测试。
- 验收命令：`pnpm lint && pnpm typecheck && pnpm test && pnpm build`，退出码须为 0。
- 你不能用浏览器。Fable 会在桌面 2 倍、手机 3 倍下截图验收，并交给 agy 复评。报告里列出应该看哪些画面。
- 不 commit，报告里按"应当成为的 commit"分组。不要过度工程化：不做主题切换器，不做暗色模式。
