# 任务 11.1b：人物声音返工（负责：sol；Fable 验收）

## 背景

11.1 的台词和好感剧情已在 worktree `.worktrees/11.1-sol` 完成，gate 通过，尚未提交。你的报告在 `docs/tasks/reports/11.1-people-and-stories.md`。好感剧情弧线、好感速度、体量都达标，这一轮不动。

Fable 的独立盲测没有过：
- **方法**：随机种子 20261114。每人随机抽 5 句，去掉说话人后打乱，交给只读子代理，只给 12 个人名和一句身份。
- **结果**：命中 **26/60 = 43%**，目标 ≥ 70%。各人命中如下：

| 人物 | 命中 |
|---|---|
| 戴夫 | 4/5 |
| 玛格丽特、拉赫曼、阿德、海伦、普里娅、陈乐言 | 各 3/5 |
| 加雷思 | 2/5 |
| 周沅、许文舒 | 各 1/5 |
| 杰米、莉娜 | 各 0/5 |

评审给的诊断，原意如下：
1. **同一句式**：大量台词是"前半句一个具体物件，后半句一句小格言收尾"，例如"看不见的地方，也得撑住重量""纸也要喘口气""舒服就算收益"。
2. **同一节奏**："短句。短句。"的冷静节奏，加上"我不问 / 不提高嗓门 / 不排任务"这类克制的否定。听起来像同一个温和、爱写旁白的叙述者。
3. **陪伴型人物可以互换**：普里娅、杰米、阿德、莉娜、许文舒的"我能听，也能不提问""我不急着答"之类，换个名字也说得通。
4. **主题相近的人缺少各自的生活细节**：同一件事（例如英语考过）的庆祝几乎是同一句话的两种写法；莉娜和阿德都为签证发愁，却没有各自的生活细节。
5. **评审建议**：
   - 给陪伴型人物加上专属的口头禅或语言习惯，例如普里娅的诊所流程用语、杰米的具体爱好、莉娜带火气的抱怨；
   - 减少"物件 + 格言"式的收尾。

## 要做的

1. **改声音表**：修改 `style-guide.md` 里的人物声音表，让每人至少有两个一眼可辨的硬特征。
   - 硬特征可以是固定口头禅或称呼方式、句子长度与标点习惯、专属话题或词汇、情绪基调（急、碎、冲、爱抱怨、爱问问题）。
   - 12 人两两之间不得共用同一个主特征。
   - 陪伴型的克制口吻最多留给一个人。
2. **按新的声音表重写台词**：镇民、周沅、家人都要过一遍。
   - **全局句式限额**：
     - 以具体物件开头、以概括性小道理结尾的句子，不超过全部台词的 10%；
     - 克制否定句式（"不问 / 不急 / 不用…"）每人不超过 3 句。
   - **共享主题**：多人都会说到的主题（考过英语、续签、换工作、节日），每个人的那句要带上自己的硬特征与生活细节，不能只换几个词。
   - **数量**：句数、情境条件比例、近况回应、11.1 新增的选择回访，都保持不少于 11.1 的水平。
3. **好感剧情里的对白**：同步按新声音调整，叙事结构不动。
4. **盲测自检**：用一个与 Fable 不同的种子自测，并把这次的句式统计写进报告：物件加格言句占比、每人克制否定句数。Fable 会另换种子再做独立盲测，目标仍是 ≥ 70%，单人不低于 2/5。
