# 任务 12.11：按 agy 复评收尾界面细节（负责：astra；Fable 验收）

## 背景

12.8、12.9 合入后，agy 复评打分从 5.0 提到 7.5（`docs/research/2026-11-15-design-review-2.md`）。复评 §二列了 8 条遗留与新问题，每条都给了截图依据、改法和文件位置。本任务只做其中不需要新美术素材的部分，§四里需要新素材的两项不做。

## 要做的

按复评 §二逐条处理，改法可以参考复评，也可以用更简单的等效做法：

1. 手机端：室内画布不要留出大块黑边；底部 Dock 不能把"现行法律 / 改革后"两张卡片拦腰截断。
2. 互动按钮：
   - 不能挡住室内的"走出家门"；
   - 不折行；
   - 触屏上不显示 E / 空格；
   - 写出将要互动的对象名，例如"互动：床"。
3. 结局页：
   - 内嵌的两栏评估跟随游戏主题，用 CSS 变量覆写，网站结果页保持原样；
   - 主操作按钮放在成就列表之前；
   - "未获得"的成就默认折叠并显示数量；
   - 合照下方留出间距。
4. 地点标签：
   - "附近"和"当前可互动"分两级显示；
   - 画布边缘的标签不能被裁掉一半。
5. 系统彩色 Emoji（🔒 ⏩ ♪̸ ☾）换成单色的内联 SVG；当前所在地点的按钮要有选中态；深色 HUD 上的键盘焦点环要看得清。
6. 对话框铭牌不能和"✕ 关闭"重叠，英文长身份时也一样；短台词下方不要留出大片空白。
7. 手机 HUD 第二行在存款五位数、属性到 100 时不能溢出；"事业"的图标要能认出来。
8. 桌面 1280×800 首屏不能截断进度卡；明亮住处改为局部暖光，不要整屏泛白；消除室内缩放时出现的 1px 绿缝。

另外，网站主站有三处遗留（复评 §一 P8 / P10）：
- 中文顶栏去掉硬拼的英文，手机端改为一行；
- 首页两个按钮在手机上等宽；
- `/simulate` 加一条纯 CSS 的步骤进度条。
