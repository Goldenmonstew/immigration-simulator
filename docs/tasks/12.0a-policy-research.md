# 任务 12.0a：政策、新闻与解析全面调研（负责：sol；Fable 验收）

## 目标

弄清 2026-11-04 来源登记之后，到今天（2026-11-15）为止，英国移民政策有哪些已生效、已公布、仍在讨论的变化；对照本仓库的引擎、参数与游戏内容，找出哪些地方过时、缺失或值得扩展。只调研、只写报告，不改代码和数据。

## 要读的现状

- `docs/SOURCES.md`（来源登记与定位约定）
- `docs/pending-details.md`

- `packages/game/src/events/policy.ts`（游戏里的政策新闻卡）

## 要查的内容

1. **官方变化**，只认官方来源：
   - Immigration Rules 与 Statement of Changes（是否已提交 Earned Settlement 的首批修改，生效日、过渡安排）；
   - gov.uk guidance 更新：Skilled Worker、Graduate、Global Talent、HPI、Hong Kong BN(O)、family、settlement、Life in the UK、English language、eVisa、ETA、费用与 Immigration Health Surcharge；
   - 议会：Hansard、委员会报告、Written Statements；
   - 2026-10-28 预算案中与移民相关的措施，以及其中哪些已有正式文件。
2. **新闻与解析**：主流媒体、律所、智库（Migration Observatory、IPPR、Institute for Government 等）的报道与分析。它们只用来发现线索和交叉验证；凡是写进结论的事实，必须回到官方原文。
3. **对照本仓库**：
   - 引擎参数、游戏新闻卡与人物处境里，哪些数字或说法已过时；
   - 哪些新变化值得进入引擎（需要规则语义）或游戏（新闻卡、事件、人物处境）；
   - 哪些仍是 `UNKNOWN`，应登记到待定细节。

## 产出

写入 `docs/research/2026-11-15-policy-update.md`：

1. **时间线表**：日期、事件、状态（已生效 / 已公布待生效 / 提议中）、官方来源 URL 与定位（页码、段落号或条款号）。
2. **候选来源**：拟新增到 `docs/SOURCES.md` 的条目，按现有格式写好草稿，包括类型、标题、URL、发布日、定位说明。不要直接改 `SOURCES.md`，也不要下载存档；登记与存档留给后续任务。
3. **差异清单**：本仓库现有内容与最新官方状态的差异，每条写明文件位置与建议。
4. **扩展清单**：
   - 带优先级，P0 / P1 / P2；
   - 每项写明负责 package、粗略规模、依赖与风险、验收方式；
   - 每项标明是"规则语义"（engine）、"参数"（policy-data）还是"游戏内容"（game）。
5. **二手来源表**：读过的新闻与解析，各一行说明用途，注明"仅交叉验证"。
