## 3. 没做或没验证的

- 不办理临时居留续期：`policy-data` 没有西班牙临时居留续期的期限和费用，居留卡到期日作为角色事实写进许可，游戏在到期前递交长期居留或入籍；到期结束本局（长期居留在到期后 3 个月内仍可递交）。所以乔尔的「长期居留」、雨桐的「入籍」在本局里显示未满足，外国人办公室的提示和新季提醒都写明了这一点。
- 入籍只做到递交：获批后的宣誓、放弃声明与民事登记（ES-N17、ES-N18）、长期居留获批后的 TIE 领卡（ES-T01）都不在游戏里。欧盟长期居留（E）等其他路径没有角色。
- DELE 价格只有 2026 年表，之后年份沿用同一价格并在活动说明里写明；代办与翻译费、cita previa 成功率、考试门槛都是游戏设定。
- 西班牙没有专属立绘、行走图和招牌：两位角色和 8 位镇民借用现有 17 人的图（`esGameArt.cast`），乐乐借用唯一的儿童图；招牌沿用通用图标；橙子、法尔通、大米等借用相近的物品图标。
- 没有心事件、地图惊喜等长期支线；这次做的是能玩通四季与两条身份路径的规模。
- 英国 e2e 的截图基线未比对（本机默认忽略截图）；按任务说明只跑了 desktop 项目的四个游戏 spec，没跑 `a11y.spec.ts`、`site.spec.ts` 与 mobile 项目（`/spain/game` 会由注册表自动加入它们的清单）；手机宽度只由 e2e 检查可走动、无横向滚动，没有另截图；音效未单独检查。

## 4. 发现与建议

- 建议在 `policy-data` 补西班牙临时居留许可的续期期限与费用（RD 1155/2024 及费用表），游戏即可办理续期、长期居留与入籍可以跨过当前居留卡。
- 引擎行为（只报告，未改）：
  - L：`trips` 只有起止日、没有 `residence.tripDetails` 的离境理由与 `irregularExit` 时，ES-L01 的普通年限投影拿不到候选日，路径显示未满足且没有最早日期；旧引擎同样输入给出 FUTURE 日期。问卷用户只填简表行程时可能遇到同样情况，游戏这边改为同时写入行程明细。
  - N：居住期间只要有一次离境，ES-N01 就需要主管机关认定连续性（PD-100），一个月探亲也会让入籍变成「无法确定」。游戏在探亲活动说明里提示了这一点。
- `about-page.test.tsx` 与 `public/sw.js` 的缓存版本本分支改为 `2026-11-24-v6-es`，其他国家合并时会在这一行冲突，按最后合并的版本号处理即可。
