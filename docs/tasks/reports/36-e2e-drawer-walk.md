# 任务 36：手机 e2e 走地点改用 walkTo

## 1. 做了什么

建议提交 `Fix: 手机 e2e 走地点复用 walkTo`，包含本报告和以下两处代码改动。

- `apps/e2e/tests/helpers.ts` 为 `walkTo` 增加可选的地点选择回调，每次尝试都会调用它。省略回调时，继续用 `click()` 选地点。
- `apps/e2e/tests/mobile.spec.ts` 中，前往「公园池塘」和「家」共用该回调，每次先轻触「镇上地点」打开抽屉，再轻触目标。聊天用例继续通过「家」菜单打开周沅对话。

## 2. 怎么验证的

- `pnpm --filter e2e exec tsc --noEmit` 和 `pnpm lint` 均通过。
- 两个测试文件的 Prettier 检查和 `git diff --check` 均通过。

## 3. 没做或没验证的

手机用例的多轮运行、e2e 全量运行、审核、提交和开 PR 由 Fable 负责。随机事件触发时的实际浏览器行为仍待验收。

## 4. 发现与建议

选中地点会立即关闭抽屉。Fable 重跑时，若遇到事件卡，可核对选第一项后是否重新打开抽屉并显示目标地点菜单。
