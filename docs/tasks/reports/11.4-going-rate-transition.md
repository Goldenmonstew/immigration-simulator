# 任务 11.4 报告：going rate 的 2026-12-01 过渡安排

分支 `claude/agitated-dubinsky-cfd671`，基于 main `90bb650`。只读核对。**引擎对截止日的处理没有错误**：没有改 `packages/engine` / `packages/policy-data`，不需要契约。

## 结论

- **条款**：过渡安排是 SRC-004 的 **SW 14.5**（"Transitional arrangements for salary on the Skilled Worker route"），只覆盖原 Tier 2 (General) 持有人，有两项，都以"申请日早于 2026-12-01"为条件：
  - **SW 14.5(a)**：同一 sponsor 下，保证发放的津贴（如 London weighting）可以算进薪资；
  - **SW 14.5(c)**：三个 SOC 2010 职业改用 SW 14.5(c) 自带的一张 going rate 表，代替 Appendix Skilled Occupations Table 2。
  - SRC-017（Appendix Skilled Occupations）里**没有**这项安排，也没有 "1 December 2026" 字样。Table 1a / 2aa / 3a 的截止是"2025-07-22 前获批"，与本项无关。
- **影响范围**：
  - 只涉及 Tier 2 (General) 起步、此后连续持有 Skilled Worker 的人，申请 permission to stay 或 settlement；入境（entry clearance）不适用。
  - 定居经 SW 24.4(a) 引入 SW 14.1–14.5，所以 (a)、(c) 都会影响 SW 24.3 的薪资判断；其中 (c) 的表还被 **SW 24.3 row E** 直接引用。
  - 涉及的表：SW 14.5(c) 的表代替的是 **Table 2**。Table 1 / 1a / 2aa / 2a / 3 / 3a 都不受影响。
- **引擎**：
  - SW 24.3 row E 与 SW 14.5 按 `docs/contracts.md` §16 的选行表"不建模（假设说明）"，引擎里没有任何读 2026-12-01 的代码；`CL-SW-SALARY` 的假设里每次都写着 row E 未建模。
  - row A–D 都不引用 SW 14.5，所以对它们来说 2026-11-30 与 2026-12-01 的结果本来就该相同。`evaluate` 复现：四个边界用例在两个日期的现行法律栏输出（按日期归一后）完全相同。
  - 因此截止日本身没有被处理错。真正的差距是早已登记的范围限制：原 Tier 2 (General) STEM 人群会被引擎落到 row C（或 A），而法律上应走 row E。是否补建模由 Fable 定，见第 4 段第 1 条。
- **来源登记**：结论不依赖指南，Rules 原文已足够。建议把指南登记为 GUIDANCE 类来源，仅作交叉验证，见第 4 段第 3 条。

### 问题 1：条款与原文

**SRC-004**（Appendix Skilled Worker，2026-10-08 版，HC 584）：

- **SW 14.5** 开头：
  > If the applicant is applying for permission to stay or settlement, the applicant was granted permission as a Tier 2 (General) Migrant and has had continuous permission as a Skilled Worker ever since, the following transitional arrangements apply:
- **SW 14.5(a)**：
  > if the date of application is before 1 December 2026 salary may also include allowances (the other restrictions in SW 14.20 also apply), providing the following conditions are met:

  条件 (i) 为同一 sponsor 工作；(ii) 津贴有保证、整个许可期都发、本地 settled worker 同等情况下也会拿到，例如 London weighting。
  - 常规规则 SW 14.2(d) 把津贴排除在薪资之外，(a) 是它的例外。
  - 原文写 "SW 14.20"，Appendix 里没有这一段，按上下文应是 SW 14.2 的笔误。不影响结论。
- **SW 14.5(b)**：DELETED。
- **SW 14.5(c)**：三个条件同时满足时，"the going rates in the table below apply, instead of the going rates listed in Table 2 of Appendix Skilled Occupations"：
  - (i) 最后一次以 Tier 2 (General) 申请时，被担保的职业在表内 SOC 2010 代码中；
  - (ii) 此后一直在该 SOC 2010 代码或对应 SOC 2020 代码下被担保（Tier 2 (General) 或 Skilled Worker 均可）；
  - (iii) "the date of application is before 1 December 2026"。

  表内容（37.5 小时周，按工时折算）：

  | SOC 2010 | 对应 SOC 2020 | 全额 going rate（options F、I） | 90%（G） | 80%（H） | 70%（J） |
  |---|---|---|---|---|---|
  | 2113 Physical scientists | 2114 | £27,190（£13.94/小时） | £25,000 | £25,000 | £25,000 |
  | 2119 Natural and social science professionals n.e.c. | 2119、2162 | £27,190（£13.94/小时） | £25,000 | £25,000 | £25,000 |
  | 2311 Higher education teaching professionals | 2162、2311、2322 | £30,940（£15.87/小时） | £27,840 | £25,000 | £25,000 |

  作对比，SRC-017 Table 2 的全额 going rate：2114 £41,500，2119 £33,700，2162 £37,400，2311 £40,600，2322 £34,900（`packages/policy-data/src/data/skilled-occupations.ts:1749`、`:1761`、`:1894`、`:1906`、`:1924`）。
- **SW 4.3**："The salary for each option will be considered as set out in SW 14.1. to SW 14.5."（续签、换雇主的打分）。
- **SW 24.4(a)**："salary will be considered as set out in SW 14.1. to SW 14.5."（定居）。
- **SW 24.3 row E**：
  - 条件："The 5-year qualifying period for settlement includes time as a Tier 2 (General) Migrant in which the applicant was sponsored for a job in one of the following SOC 2010 occupation codes"：2111、2112、2113、2114、2119、2150、2311。
  - general salary：£25,000。
  - going rate："At least the going rate in the table at SW 14.5(c), if the applicant has continued to be sponsored in that SOC 2010 occupation code, or the equivalent SOC 2020 occupation code shown in Table 2 of Appendix Skilled Occupations, ever since. At least the relevant going rate in Tables 2 to 5 of Appendix Skilled Occupations, in other cases."
  - row C、D 的条件里都写着 row E 不适用时才用，所以 row E 优先于 C / D。

**SRC-017**（Appendix Skilled Occupations，2025-11-11 版，HC 1333）：全文去标签后搜 "1 December"、"2026"：没有与本项相关的条文。

**指南**（*Sponsor a Skilled Worker*，version 04/26，未登记）与 Rules 一致：

- SK6.30：going rate 有一项针对原 Tier 2 (General) 指定职业的过渡安排。
- SK6.48–SK6.49（物理 p43，印刷页 42–43）：options F–J、三个条件，第三条为 "their application for permission is submitted before 1 December 2026 (after which this transitional arrangement will end)"；表的数字与 SW 14.5(c) 相同。

### 问题 2：影响范围

| 情形 | SW 14.5(a) 津贴 | SW 14.5(c) going rate 表 |
|---|---|---|
| 入境（entry clearance） | 不适用（开头限定 permission to stay 或 settlement） | 不适用 |
| 续签 / 换雇主（permission to stay） | 适用（经 SW 4.3），须同一 sponsor | 适用（经 SW 4.3），只代替 options F–J 用的 Table 2 |
| 定居（SW 24.3） | 适用（经 SW 24.4(a)），各行都可能受影响 | 只与 row E 有关（row C / D 查 Table 2 时理论上也会被代替，但 row E 的条件更宽且优先，满足 14.5(c)(i)–(ii) 的人都已落在 row E） |

人群：只限原 Tier 2 (General) 持有人。Tier 2 (General) 在 2020-12-01 关闭（指南 p7 术语表），但 2020-11 前获批的 Tier 2 许可最长可到 2025 年，所以 2026 年申请定居的 5 年合格期仍可能含 Tier 2 时间。

表：只涉及 Table 2（被 SW 14.5(c) 代替）以及 row E 引用的 Tables 2–5。不涉及 Table 1 / 1a / 2aa / 2a / 3a。

**2026-12-01 之后 row E 还能不能用 SW 14.5(c) 的表——原文没有说清楚：**

- 读法一：row E 直接引用"the table at SW 14.5(c)"，自身条件只看 SOC 连续性，不看申请日，所以表继续适用。
- 读法二：SW 24.4(a) 把 SW 14.5 整段（含 (c)(iii) 的日期条件）带进定居；12-01 起表失效，row E 落到"in other cases"，查 Tables 2–5。
- 两种读法对 row E 的 general salary（£25,000）没有影响；只影响 going rate。例：SOC 2311、年薪 £35,000，读法一 PASS（≥ £30,940），读法二 FAIL（< £40,600）。
- 指南没有讲定居，不能裁决。按 AGENTS.md 应为 `UNKNOWN`，见第 4 段第 2 条。

### 问题 3：引擎是否正确

**实现**：

- `settlementSalaryRow`（`packages/engine/src/rules/current-law.ts:1699`）只返回 row A–D；`SalaryRow` 类型的注释写明 "row E is not modelled"（`:1202`）。
- `CL-SW-SALARY` / `CL-SW-GOING-RATE` 每次都在假设里写"SW 24.3 row E（5 年期含 Tier 2 (General) 下的 STEM 类 SOC 2010 职业）未建模"（`:1752–1755`）。
- `GOING_RATE_TABLES`（`:1927`）：A / B 查 `1 → 1a`，C / D 查 `2 → 2aa → 2a`，没有 SW 14.5(c) 的表。
- 参数文件 `packages/policy-data/src/parameters/current-law-2026-11.ts:131–134` 同样注明 row E 不建模；没有任何 2026-12-01 参数。
- `ImmigrationEpisode.salary` 是用户填写的一个年薪数字，引擎不区分基本工资与津贴，没有 SW 14.5(a) 的判断。
- 路线表（`packages/policy-data/src/routes.ts`）没有 Tier 2 (General)；这类时间只能填成 `SKILLED_WORKER` 或 `OTHER`。
- 这些与 `docs/contracts.md` §16 的选行表（row E："Tier 2 (General) STEM 遗留，不建模（假设说明）"）一致。

**边界复现**：调 `evaluate`，比较 2026-11-30 与 2026-12-01 的现行法律栏（`current-law-2026-11`）。每个用例都是两段 SOC 不变的许可：2019-06-01 → 2022-05-31（代表 Tier 2 (General) 时间）、2022-06-01 → 2027-05-31，其余字段取测试 helper `timeline()` 的默认值（B2、Life in the UK 已过）。

| 用例 | 两个日期的结论 | CL-SW-SALARY | CL-SW-GOING-RATE | 输出相同 | 按法律（11-30） | 按法律（12-01） |
|---|---|---|---|---|---|---|
| SOC 2311，£35,000，Tier 2 段填 `SKILLED_WORKER` | LIKELY_NOT_ELIGIBLE，10 年 | row C £31,300 PASS | row C Table 2 £40,600 FAIL | 是 | row E：£25,000 PASS，£30,940 PASS | row E：£25,000 PASS；going rate 两读法 PASS / FAIL |
| 同上，Tier 2 段填 `OTHER` | LIKELY_NOT_ELIGIBLE，10 年 | row C PASS（起点 2022-06-01） | row C Table 2 FAIL | 是 | 同上 | 同上 |
| SOC 2311，£41,000 | LIKELY_ELIGIBLE，5 年 | row C PASS | row C Table 2 PASS | 是 | PASS | PASS |
| SOC 2114，£30,000 | LIKELY_NOT_ELIGIBLE，10 年 | row C £31,300 FAIL | row C Table 2 £41,500 FAIL | 是 | row E：£25,000 PASS，£27,190 PASS | row E：£25,000 PASS；going rate 两读法 PASS / FAIL |

"输出相同"指整个现行法律栏 JSON（全部规则、解释、假设）在把两个日期字符串归一后逐字相同。两天都带有 row E 未建模的假设。

**判断**：

- 截止日：引擎没有建模 SW 14.5，也就没有处理错 2026-12-01；row A–D 在边界前后不变，与原文一致。
- 范围差距（已知、已登记于契约）：原 Tier 2 (General) STEM 人群在 11-30 当天按法律走 row E 可能通过，引擎给出 row C / A 的 FAIL，只靠假设提示。12-01 起这一差距在 going rate 上可能缩小（若取读法二），但 row E 的 £25,000 general salary 与 row C 的 £31,300 之间的差距不受截止日影响（见 SOC 2114 用例）。
- 所以不提交契约与修复方案。
