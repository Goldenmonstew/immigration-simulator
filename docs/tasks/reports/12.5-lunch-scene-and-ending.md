### Fable 应检查的画面与存档构造

在本 worktree 用 `pnpm --filter web dev` 启动唯一一个开发服务，打开 `/game`。桌面和 375px 宽度都检查聚餐、背包与结局；中文和 English 各检查一次。以下脚本仅用于本地验收存档，不代表实际游玩结果或政策评估案例。

先新开一局林遥、完成开场选择，回到角色选择页，以免游戏计时自动覆盖控制台写入。下面脚本保留原存档于 `sessionStorage`，构造夏季周末上午的聚餐邀请。执行后刷新，在林遥卡片点“继续”。每次要复用 `load125` 都需重新粘贴函数定义。

```js
function load125(change = () => {}) {
  const key = 'uk-immigration-life-v3:skilled-worker';
  const backupKey = '12.5-original-save';
  if (!sessionStorage.getItem(backupKey))
    sessionStorage.setItem(backupKey, localStorage.getItem(key));
  const s = JSON.parse(sessionStorage.getItem(backupKey));
  Object.assign(s, {
    year: 1, quarter: 3, date: '2025-07-15', dayNumber: 7,
    flags: ['quarter-board-community-lunch'], friendship: {},
    inventory: { biscuits: 1, 'baked-potato': 1, 'seed-tomato': 1 },
    plots: [{ growth: 0 }], log: [], diary: [], heard: [],
    firedEvents: [], eventQueue: [], achievements: [],
  });
  Object.assign(s.day, {
    index: 1, kind: 'weekend', date: '2025-07-19', minute: 480,
    weather: 'sunny', place: 'home', done: [], talked: [], gifted: [],
    deliveries: [],
  });
  s.stats.money = 5000;
  s.quarterStart = { ...s.stats };
  for (const key of ['pendingEvent', 'ending', 'outcome', 'trip']) delete s[key];
  delete s.day.festival;
  delete s.day.resumeMinute;
  change(s);
  localStorage.setItem('uk-immigration-life-v3:skilled-worker', JSON.stringify(s));
  location.reload();
}
load125();
```

验收顺序与预期：

1. **准备前 → 准备后**：去村绿地，看到长桌与餐盘、玛格丽特；入口仍能点击、路径不穿桌。选择免费借桌椅，关闭弹层，看新增两张椅子和“你借来的桌椅已摆好”。从基线分别重做带饼干与带烤土豆，检查食物及贡献文字立即出现；饼干与碗装菜品图不同。没有准备也应保留基础长桌并能在中午入席。
2. **入席 → 合照／日记**：用 `load125(s => { s.day.minute = 720; });` 开始空手路线，去绿地手动“入席”。背包显示“邻里聚餐合照”的专用照片图标。继续结束该周末及节日代表日，季度小结“这一季的日子”中第 2 天应能看到入席与获得合照的文字。可送出合照，后续结局仍保留合影回忆。
3. **收场与节日**：分别用 `load125(s => { s.day.minute = 959; });` 和 `960` 核对 16:00 消失；去掉公告旗标、改为工作日、改为 `special` 或下一季，都不应显示聚餐。合成共存探针 `load125(s => { s.day.minute = 780; s.day.festival = 'summer-fair'; });` 应看到北侧摊位与南侧长桌互不遮挡；这是视觉测试组合，正常日历中聚餐与夏日集市分属两天。
4. **结局四类与空状态**：用下面替换脚本的最后一行，构造已发生四类经历的展示存档。应出现人物、家具、合照、作物四个回忆位，先于成就；两栏评估与原叙事仍在。375px 下回忆区为一列，没有横向溢出。另用 `load125(s => { s.plots = []; s.flags = []; s.ending = 'left'; });` 检查完全没有回忆标题、空卡或占位内容；背包中的饼干、土豆菜品和种子不能触发回忆。
