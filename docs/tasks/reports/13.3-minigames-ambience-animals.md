### A3. 要听的声音

第一次进入默认静音时应保持静音；点现有声音开关后才听音。每种录音至少听三圈；打开背包或钓鱼菜单可暂停游戏时钟、固定在当前地点听，环境声仍保留。

| QA 状态 | 预期音层 |
| --- | --- |
| 家中，任何天气 / 时间 | 季节 BGM + 很轻的室内底噪；没有室外鸟、雨或池塘水声。 |
| 晴 / 多云，10:00 户外，远离池塘 | BGM + 鸟鸣。 |
| 雨天，户外 | BGM + 雨声；不叠鸟鸣。 |
| 晴天白天靠近池塘 | BGM + 鸟鸣 + 低水声；走远后水声淡出。判定是玩家距池塘锚点约 7 格内，不依赖 `day.place`。 |
| 雨天靠近池塘 | BGM + 雨 + 水；重点听是否过密或掩盖原音乐。 |
| 18:00 以后，晴天远离池塘 | 没有鸟鸣；靠近池塘仍有水声。雪天也没有鸟鸣。 |
| 反复静音、隐藏标签页、返回、退出游戏 | 所有声音一起停 / 恢复；恢复后不多出第二份循环；退出后不再播放。慢网加载时静音或离开，下载完成也不应突然播放旧地点声音。 |

检查循环接缝没有可闻点击、停顿或明显音量跳跃；检查出入房屋和池塘边界时约 350 ms 淡入淡出。代码和采样检查已过，**混音舒适度、设备实际解码与接缝听感仍待 Fable 确认**。
