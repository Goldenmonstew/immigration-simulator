### 为什么选五月节

五月节每年春季都有，不像秋季两个节日需要隔年交替，容易完整验证相邻两年的区别。现有 `may-ribbons` 已有当天动作和三版结果，能直接接上准备与散场；彩带、路牌也适合同时表达参与方式与留下的物件。两种准备均免费，不要求购买物品。

### 五月节状态与菜单契约

新增可选字段，既有 v3 存档与公开函数签名不变，不需要迁移：

```ts
GameState.mayDay?: {
  year: number;
  preparation?: 'ribbons' | 'signs';
  participation?: 'dance' | 'guide';
  participationDay?: number;
  indoors?: boolean;
  followupSeen?: boolean;
}
```

- `year` 是从 1 开始的游戏年；仅显式选择五月节行动时写入。下一游戏年首次准备或参与会建立新记录，上一年的准备不算本年贡献。未操作的新局和旧档可以没有该字段。
- `participationDay` 使用单调递增的 `dayNumber`；仅实际选择当天小操作后写入。准备、泛用 `festival` 逛摊位、快进均不冒充这条链的完成。
- `indoors` 记录参加当天是否为 rain / snow；准备本来就在室内。`followupSeen` 仅回访后置为 true，读档保留。

### 地图接口与存档契约

新增两个公开函数，保留既有 API 的名字、参数与返回形状：

```ts
mapSurprises(state: GameState): MapSurprise[]
approachSurprise(state: GameState, anchor: AnchorId): GameState

interface MapSurprise {
  id: 'biscuit-cat' | 'swap-box' | 'lost-mitten';
  phase: 'clue' | 'trace';
  anchor: AnchorId;
  text: Text;
  expiresMinute?: number;
}

GameState.surpriseRecords?: {
  id: 'biscuit-cat' | 'swap-box' | 'lost-mitten';
  choiceId: string;
  dayNumber: number;
}[]
```

- `mapSurprises` 是只读查询，不抽签、不改随机游标、不触发弹窗。astra 先画 `phase: 'clue'`；玩家走到对应锚点的交互距离内，再调用 `approachSurprise`。game 没有坐标／距离状态，距离判定由画面侧负责；仅进入某个地点或读信不会打开惊喜。
- 靠近后走原 `currentEvent` / `resolve` 菜单；事件 ID 为 `surprise-<id>`。不在 commonEvents 抽取池，不进入 morning / letter / place 投递队列，不参与季末补读或快进补发。错误锚点、过期、已有 pending event、旅途中或结局状态均不会开新事件。
- 打开菜单时原 `firedEvents` 记录事件 ID；选择结算时写入 `surpriseRecords`。无论在待选菜单还是领取之后 JSON 存读档，都不会再开同一惊喜；已领取的物品数量保留。字段缺省视为空，不追补旧档已经错过的代表日。
- 结算后同一查询返回 `phase: 'trace'`，保留相同 ID／锚点和对应分支的双语描述；无 `expiresMinute`。痕迹在后续日／季保留，不再开放领取。出国／结局时地图查询返回空；记录仍在存档。
- `surpriseRecords` 是经历，花盆是否仍在背包不决定能否领取。`swap-pot` 为已登记的 gift 物品，没有价格，也不扩展种植或交易机制。其他结局只给 2 点心情，不改金钱、工作、许可或规则语义。选择结算按现有事件菜单处理，不额外推进时钟。

### 三个异常出现在哪里、显示什么、持续多久

每个主题每局只有一次机会，分别放在开局的前三个游戏季度中；不要求公告恰好被抽到。以下均为虚构游戏排期，不是政策或现实节庆日期。

令主题索引 `i` 依次为 0、1、2，其出现代表日为：

```ts
dayNumber = i * 3
  + ((Math.imul(state.seed ^ (i + 1), 2654435761) >>> 0) % 3)
```

也就是从 `dayNumber` 的 0–2、3–5、6–8 各选一天。初始 seed 相同就完全一致，不消耗 `randomState`。三项均在该代表日 **09:00（含）–18:00（不含）** 显示，错过时窗或睡到下一天就过期，下一季／下一年不重排。读档恢复同一时间点会显示同一线索；已经打开或结算的不会重开。

| 惊喜 ID／锚点 | 未参与时的异常 | 两种结果 | 分支场景痕迹 |
| --- | --- | --- | --- |
| `biscuit-cat` / `high-street-west` | 小店窗台下晃动的条纹猫尾巴；改编自饼干寻猫公告 | `wait`：隔开距离等主人带猫包接走；`call`：按拉赫曼便条报位置、让开空间，后见已接回家的字条 | 倒扣的水碟；或门边「已接回家，谢谢」字条。两种均有结尾，不追猫。 |
