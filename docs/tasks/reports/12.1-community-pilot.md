### 玩法与时段

- `community-lunch` 复用原 `summer-shade` 在夏季随机公告池中的位置，不增加公告池条数、不改变抽样顺序，仍每季抽取 2–3 条；不是每年必发。公告有效至本季结束，写明本季代表周末的实际日期、村绿地、12:00–16:00，以及最晚 15:00 入席。
- 准备和聚餐都在现有 `green` 地点。准备在代表周末上午完成：借桌椅耗时 30 分钟，或带食物耗时 15 分钟；必须在 12:00 前完成，且只能选一条准备分支。
- 食物分支可用现有厨房做出的 `baked-potato`，也可在小店买 `biscuits`（当前游戏价格 £3）。交付时扣一份物品。没有钱、作物或食物时，仍能免费借桌椅或空手参加。
- 入席耗时 60 分钟，可于 12:00–15:00 开始。结果分别回应桌椅、食物、空手到场；心情和玛格丽特好感沿用现有节日活动数值。公告周末 07:00–16:00 玛格丽特在绿地，雨雪也在；其他日子的作息沿用原规则。
- 合照作为永久纪念物保留，没有新增归还支线；也可按现有送礼机制送出。即使送出，后续年份也不再补发。

### 旗标契约

| ID | 设置时机与含义 | 清除时机 |
| --- | --- | --- |
| `quarter-board-community-lunch` | 夏季随机抽到聚餐公告时设置，使用现有公告前缀 | 本季结束，随现有 `quarter-*` 旗标清除 |
| `quarter-community-lunch-tables` | 完成借桌椅，供当天结果及场景辨认贡献 | 本季结束 |
| `quarter-community-lunch-food` | 完成任一带食物行动；与桌椅分支互斥 | 本季结束 |
| `quarter-community-lunch-attended` | 手动完成入席；为下一季回访留下交接标记 | 本季结束，清除前据此设置回访旗标 |
| `community-lunch-attended:YYYY` | 手动入席时设置；`YYYY` 取 `state.day.date` 的日历年，不取游戏年序号。该日历年内所有聚餐行动随即隐藏 | 不清除，跨年保留记录 |
| `community-lunch-photo-received` | 首次入席并发出合照时设置；不以当前背包数量判断是否发过 | 不清除 |
| `quarter-community-lunch-followup` | 参加聚餐后的季末设置，在下一季开放回访 | 与玛格丽特首次交谈后清除；若整季未见，下一次季末清除，避免多年后仍说“上季” |

`margaret-recent-community-lunch` 是新增回访台词 ID，以回访旗标为条件，优先于普通台词。说完记入 `heard`，但不设 `once`：以后年份若再次参加，新的回访旗标仍允许回忆新一年的聚餐。回访另写入现有日记日志，行动 ID 为 `community-lunch-followup`，该 ID 不是可点击的菜单项。
