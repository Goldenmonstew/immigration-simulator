## 约定

- 每个任务在 `.worktrees/<任务号>-<简称>` 的独立分支上做；brief 写明范围、文件、验收命令和编号段。
- 规则改动沿用硬规则：数字要有 SRC 定位；官方未定的输出 `UNKNOWN` 并登记 PD；不写死裸数字。
- 审核口径沿用此前经验：只有常见情形下的过早日期或错误状态、且有可复现输入的列为"问题"；多因素叠加的罕见组合列为"风险"，写进报告。
- 门禁（`pnpm lint && pnpm typecheck && pnpm test && pnpm build` 与桌面 e2e）由 Fable 串行运行；同一时间写同一组文件的实现者不超过一个。
- 合并顺序按依赖；并行分支在前一个合并后合入 main 再跑门禁。
