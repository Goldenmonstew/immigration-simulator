# 任务 12.3：家里看得见的变化与小镇的季节（负责：astra；Fable 验收）

## 背景

12.0b 调研（`docs/research/2026-11-15-content-expansion.md` §1.7、§4 E02／E09）发现，Phase 11 新增的消费在画面上没有任何体现：
- 阅读椅、厚窗帘、台灯、明亮住处，核心会设置旗标 `furnished-reading-chair` / `furnished-warm-curtains` / `furnished-desk-lamp` / `brighter-home`，并结算持续效果；
- 但 `apps/web` 没有读取这些旗标，买前买后家里一模一样。

此外，普通日的村绿地中心是空的；小镇地图也不随季节变化。

## 要做的

1. **家具可见（E02）**：
   - 在家的室内地图（`home.json` 与场景）里，为三件家具各设一个固定位置。买了才显示，刷新或读档后仍在。
   - 明亮住处的表现：租住期间室内更亮、更暖（光照遮罩或色调都行），退租后恢复原样。
   - 素材优先用仓库里已有的 Kenney Roguelike Indoor（CC0）图块；需要新素材时，只用 CC0 并更新 `ATTRIBUTION.md`。
   - 家具不能挡住床、厨房、书桌、信箱、出口这些触发点和动线。
2. **普通日的村绿地（E09 前半）**：在村绿地加少量非节日的实物（例如长桌、花坛、自行车架、晾着的彩旗架），让它平时也像个地方。节日时的摊位照旧，两者不叠在一起；不挡寻路和 NPC。
3. **小范围四季景观（E09 后半）**：按游戏季节，给小镇的树木和草地做轻量的变化，比如色调或替换几种图块。春夏秋冬能分出来即可，冬天可以偏冷灰。不重画地图，也不做逐帧动画。

## 约束

- 只改 `apps/web/**`，外加报告 `docs/tasks/reports/12.3-visible-home.md`。不改 `packages/game`。
  - 只读 `GameState.flags`，以及现有导出的季节信息（`quarterAt` 等）。
  - 发现缺少需要的导出，就写进报告，不要自己改 game。
- 测试：
  - 场景或会话层的单元测试：给定 flags，家具应显示或隐藏；给定季节，选出正确的景观状态；
  - 已有 web 测试全部通过。
- 验收命令：`pnpm lint && pnpm typecheck && pnpm test && pnpm build`，退出码须为 0。
- 你不能用浏览器，视觉验收由 Fable 在浏览器里做。报告里写清楚：
  - 每件家具的坐标与图块 ID；
  - 季节景观的实现方式；
  - Fable 应该去看哪些画面。
- 不 commit，报告里按"应当成为的 commit"分组。不要过度工程化：不做家具编辑器、自由摆放或新的购买系统。
