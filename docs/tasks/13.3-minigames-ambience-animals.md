# 任务 13.3：钓鱼与厨房小游戏、环境音、小动物（负责：astra；Fable 验收）

## 背景

12.0b 调研（`docs/research/2026-11-15-content-expansion.md` §1.7、§4 E10、E11）提到：
- 钓鱼只有浮标和咬钩窗口，缺少挥竿和收竿的表现，鱼种都共用一张图；
- 厨房选完配方就直接结算；
- 小镇没有环境音，也没有小动物。

界面已是暖木主题，13.1 新增了原创像素素材。

## 要做的

1. **钓鱼**：
   - 加上挥竿、等待、咬钩、收竿的表现；
   - 6 种鱼各有可辨认的图标，可以原创像素图；
   - 钓上来时有一个小展示（鱼名、首次收录提示），与 12.7 的收藏册衔接；
   - 键盘、鼠标、触屏都能操作；
   - 给一个简易模式（例如放宽咬钩窗口），失败不影响其他系统。
2. **厨房**：选好配方后，加一段简短的操作，例如按顺序放食材、搅拌、出锅（2–4 步，点击即可），做完显示成品图和一句评语。
   - 结果仍然交给 game 的现有接口结算，不改数值；
   - 可以跳过操作，直接得到相同结果。
3. **环境音**：
   - 按天气和地点叠一层环境音：雨声、鸟鸣（白天户外）、池塘水声（靠近池塘）、室内安静底噪；
   - 沿用现有的静音开关、页面隐藏暂停和音量设置，不能和 BGM 叠出噪音，循环无缝；
   - 只用核实过的 CC0 音频（OpenGameArt、freesound 中的 CC0 条目等），在 `ATTRIBUTION.md` 登记；总体积要小，单个文件压成 OGG。
4. **小动物**：
   - 两到三种，例如池塘的鸭子、街上的猫、菜地的知更鸟；
   - 按季节和时间出现，有简单的游走或待机动画；
   - 不挡寻路，不能互动也可以；
   - 尊重 `prefers-reduced-motion`；
   - 素材用 CC0 或原创像素。

## 约束

- 只改 `apps/web/**`，外加报告 `docs/tasks/reports/13.3-minigames-ambience-animals.md`。不改 `packages/game`；缺接口就写进报告。
- 测试：
  - 钓鱼各状态，以及简易模式；
  - 厨房步骤与跳过的结果一致；
  - 环境音按天气、地点和静音状态的选择逻辑；
  - 小动物按季节和时间的出现与避让；
  - 已有 web 测试全部通过。
- 验收命令：`pnpm lint && pnpm typecheck && pnpm test && pnpm build`，退出码须为 0。
- 你不能用浏览器。报告里写清楚 Fable 要看、要听哪些画面和声音，以及怎样构造对应的存档。附素材清单：文件、来源 URL、作者、许可、大小。
- 不 commit，报告里按"应当成为的 commit"分组。不要过度工程化。
