# 任务 12.1：两处台词残留与社区聚餐试点（负责：sol；Fable 验收）

## 背景

12.0b 调研（`docs/research/2026-11-15-content-expansion.md` §1.6、§4 E01／E03、§5.1）的结论是：文字库不是瓶颈；真正缺的是生活行动走到可见结果，并且下次见面有人记得。本任务先修两处已核实的台词残留，再做一个完整的社区活动试点。试点验收通过后，第二波再推广到其他活动。

## 一、台词残留（E01）

1. **杰米**：`packages/game/src/family.ts` 的 `jamie-daily-31..36` 是下班后的台词。它们用 `forbids: ['family-jamie-unemployed', …]` 排除，这个旗标表示"曾经失业"，而且复工后不会撤掉，所以杰米复工后这六句永远不会出现。
   - 改成按"当前是否失业"判断：失业期间不出现，复工后恢复。
   - 失业期间说下班的话不合理。
   - 用最直接的办法，比如判断复工旗标；不要新造一套状态系统。
2. **阿德**：`packages/game/src/npcs.ts:3198`、`:3202` 是十心剧情的两条选择回访，还留着已经去掉的会议腔（"另案讨论""会前确认"）。
   - 本 brief 明确允许改这两句的措辞。
   - 改后要保留所回应选择的含义，并符合 `style-guide.md` 里阿德的条目。

## 二、社区聚餐试点（E03a）

用现有的公告与地点，做一条"邻里聚餐（Big Lunch 式）"活动链。素材依据见调研报告 §3 的 L20–L22。

1. **看见邀请**：公告栏出现聚餐公告。复用现有公告机制，不新建任务系统。
2. **准备**：在公告有效期内的某个代表日，玩家可以在一个现有地点（村绿地、小店或家里任选其一）完成准备行动。准备有两条合理分支，例如：
   - 借桌椅、帮忙布置；
   - 做一道菜带去，可以用厨房已有的菜谱或买现成的。

   两条分支都不能要求高额花费；钱紧时也要能参与。
3. **当天**：在村绿地参加聚餐，结果按准备分支不同。至少要有一位现有 NPC 在场并回应你的贡献，比如玛格丽特或拉赫曼。
4. **回访与痕迹**：
   - 下一季见到这位 NPC 时，有一句回访台词提到这次聚餐。
   - 玩家得到一件纪念物，例如合照、借来的盘子要还、一张手写菜谱。纪念物要么作为物品，要么作为旗标，并在背包或日记中可以看到。
   - 归还或保留可以是一个小选择。
5. **错过与重复**：
   - 错过准备，仍可以只去当天。
   - 错过当天，就留到下次公告；每年最多一次，不重复发纪念物。
   - 快进时不自动完成这条链。

**状态契约**：在报告里写清楚：
- 新增的旗标、物品与行动 ID；
- 各自何时设置、何时清除；
- 客户端需要显示什么。

第二波由 astra 按这个契约做场景表现（E03b），本任务不改 `apps/web`。

- 公开 API 的名字和形状不变。新行动走现有的 `activities` / `locationActions` 机制，客户端不需要改就能显示菜单项。

  - 聚餐链覆盖两条准备分支、只去当天、错过、存读档后状态保持、每年不重复、快进不自动完成；
