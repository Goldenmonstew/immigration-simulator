# 任务 13.1：人物立绘、游戏横幅与店铺招牌（负责：astra；Fable 验收）

## 背景

agy 复评（`docs/research/2026-11-15-design-review-2.md` §三、§四"需要新素材"）指出：
- 选人页和对话框把 16×16 的行走小人放大到 80×80 当立绘，没有表情；
- `/game` 选人页与网站首页的游戏入口缺一张小镇横幅；
- 店铺缺各自的招牌，地图只能靠文字标签认地方。

界面已是 12.9 / 12.11 的暖木主题。

## 要做的

1. **找素材**：先在 OpenGameArt、itch.io、GitHub 上找 **CC0** 的像素人物头像或半身像、小镇风景、店铺招牌素材。
   - 每个候选都打开它的许可页，核实确实是 CC0。CC-BY、CC-BY-SA、"免费但须署名"或许可不明的一律不用。
   - kenney.nl 拒绝脚本下载，请改用 OpenGameArt 或 GitHub 上的镜像。
   - 下载到 `apps/web/public/game/assets/<包名>/`，在 `ATTRIBUTION.md` 写清楚来源 URL、作者、许可，并保留原许可文件。
2. **没有合适 CC0 素材时**：可以自己原创像素图（PNG 或 SVG，例如用脚本逐像素绘制），按 CC0 登记为项目原创。不得临摹或改绘有版权的游戏角色、美术或标志。
3. **人物立绘**：
   - 3 位主角、8 位镇民、4 位家人，每人至少 3 种表情：平常、开心、担心或难过。尺寸统一，48×48 或 64×64 都可以。
   - 外观要与现有行走图大致对应（发色、衣服主色），并且一眼能分出 15 个人。
   - 接入对话框头像、选人页、镇民列表、结局回忆。
   - 对话框里的表情：游戏现有的表情或心情数据能用就用；没有就按好感剧情和普通台词给一个合理的默认，在报告里说明映射规则。不要改 `packages/game`。
4. **横幅**：一张小镇风景横幅，用在 `/game` 选人页顶部和网站首页的游戏入口卡片上。桌面和手机都要好看，手机上可以裁切。
5. **店铺招牌**：给咖啡馆、街角小店、酒吧、GP 诊所、图书馆、语言学校、市政厅、签证中心、火车站加像素小招牌或图标，挂在建筑门口附近，不挡寻路。

## 约束

- 只改 `apps/web/**`，外加报告 `docs/tasks/reports/13.1-art-assets.md`。不改 `packages/**`。
- 不引入新的 UI 库或依赖。图片总体积要合理，报告里列出新增素材的总大小。
- 测试：
  - 头像映射：15 人都有，表情回退正确；
  - 招牌位置不挡寻路；
  - 已有 web 测试全部通过。
- 验收命令：`pnpm lint && pnpm typecheck && pnpm test && pnpm build`，退出码须为 0。
- 你不能用浏览器。Fable 会截图验收并请 agy 评美术。报告里附一张素材清单表：文件、尺寸、来源或原创、许可。
- 不 commit，报告里按"应当成为的 commit"分组。
