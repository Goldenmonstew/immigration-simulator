# 任务 12.8：画面文字清晰度与低成本界面硬伤（负责：astra；Fable 验收）

## 背景

用户反馈"画面里面的文字好模糊"。Fable 用 2 倍像素无头截图确认，问题出在小镇画布里的文字：
- 地点标签（如"公告栏""村绿地"）、信箱角标、飘字、镇民表情气泡，都是 Phaser Text；
- 字号 8–9px，按 1 倍分辨率画进纹理，再被镜头放大 2.5–3 倍；
- 游戏开着 `pixelArt: true`，用的是邻近取样；
- 画布本身也不随屏幕像素密度渲染，Retina 屏上浏览器还要再放大一次。

结果中文笔画糊成一团。网页 DOM 部分的文字是清晰的。

agy（Gemini）的设计评审见 `docs/research/2026-11-15-design-review.md`，§二是模糊的修法，§四列了前 10 个问题，§六第一档是低成本项。本任务做文字清晰度，以及其中不涉及整体换肤的硬伤；换肤留给 12.9。

## 要做的

1. **画布文字清晰**（评审 §二）：小镇和室内画布里所有给人读的文字，在 2 倍和 3 倍屏上都要清晰，不能有锯齿或发糊。涉及：地点标签、信箱角标、飘字、心形与收获提示、镇民表情气泡。
   - 推荐方案 A：把地点标签等改为与画布坐标同步的 DOM 叠加层。
   - 也可以用方案 B：给 Text 设足够高的 `resolution`，并单独处理过滤方式。
   - 无论哪种，镜头移动和缩放时标签都要跟准位置；不能挡住点击；性能不能明显下降。
   - 标签不要盖住建筑屋顶（评审 P3）。
2. **程序化聚焦的黄黑大框**（P2）：
   - 问卷、结果页里为可访问性而聚焦的标题（`tabIndex=-1`）不要显示焦点框；
   - 点地点按钮后画布获得焦点时不要显示整圈粗框；
   - 弹窗打开时不要让首个按钮带粗框，除非用户是用键盘操作的。
   - 键盘用户的 `:focus-visible` 仍要清楚可见。
3. **跨页硬伤**（P8）：
   - 首页次按钮的文字色被 `.body a` 盖掉了，要修正；
   - 政策页（以及说明页的卡片顶边）补上"已公布、未生效"的黄色标记和琥珀色顶边，与结果页一致。
4. **地点按钮断字**（P5）：
   - 右侧地点按钮不要出现"关/门"被拆成两行的情况；
   - 去掉在这里不合适的 `overflow-wrap: anywhere` 继承；
   - 关门状态改为不拆字的小标记，例如末尾的小锁或"关"字角标，具体自定。
5. **弹窗细节**（P7）：
   - 选项列表和下方按钮之间、"处理完事件后继续快进"上方，要有间距；
   - 关闭按钮的文案要符合语境：在家里或聊天时不写"回到小镇"，可以统一为"✕ 关闭"，或按场景写"离开"；
   - 打字机"显示整句"按钮出现、消失时，下方按钮不要跳动；
   - 聊天里的心形改用暖红色。
6. **室内画布四周露出的草绿色背景**（P6 后半）：改成与室内协调的深色。
7. **字体栈**（P10）：中文字体放在 Arial 之前；数字用 `tabular-nums`。
