# 小镇事件文案风格

人物和情节均为虚构。每张卡写一件具体的小事：NHS 候诊室的塑料椅、火车罢工后挤满人的站台、房东的邮件、超市黄标、淋湿的袜子、同事带来的饼干、council tax 信封。先让人看到生活，再看到选择；不要用政策字段替代故事。

标题短一点，中文正文每条不超过 60 字；英文同步表达事实与选择，读起来像日常对话，不逐字硬译。轻松、有一点幽默，笑点落在处境，不落在国籍、职业、家庭结构或任何群体身上。不说教，不写“你应该”，不给人物贴道德分数。

两个或三个选择都要像角色真的会做的事，并写出眼前代价。后果落在角色身上：房东扣了押金，林遥没睡好，同事留下了便当；不写“连续居留属性减一”这样的台词。约一半事件只改变生活属性与叙事。连锁的后一张记得前一张发生了什么，不凭空改变关系或工作。

机制说明只放在选项的 note，一句话说清记录了什么，不预测获批。涉及签证、犯罪或福利时交给引擎显示后果，游戏不另写规则。虚构工资、开支和考试游戏阈值不冒充政策门槛；真实费用从有来源的参数读取。出国行动从当天出发；归来后的季初才用实际日历日期记离境，不把未来行程算作已发生。事件不免费发放续签，相关手续在签证中心完成。

## 镇民台词

像熟人随口说的话：湿外套、垃圾桶、候车牌、茶杯与小屋钥匙都能入话。中文每句不超过 40 字，中英表达同一件事。笑点落在处境上，不拿身份取笑。让熟悉程度、天气、季节与玩家近况自然进入对话；不讲规则数字，不预测获批，不说教。

好感剧情写成一小场戏：正文用 `\n` 分隔为 3–6 段，中文每段不超过 50 字，合计 120–260 字（不计换行，计标点）；英文段数相同，并保留相同的事实与动作。对白用「」与 “ ”，中文标题不超过 10 字。给出两到三个具体动作作为选择，不用“收好这一刻的小东西”等通用句；效果只改变生活属性、好感、旗标与叙事。五段从认识走到信任，10 心留下一个以后仍在的小习惯或物件。提到时段、日子、天气、季节、熟络程度或前事时，挂上相应条件或旗标。

### 句式限额与共享主题

- “具体物件起句，概括性小道理收尾”的台词全库不超过 10%。物件后的具体操作、失败或现场包袱不算格言；把操作升成人人适用的道理就算，不能靠换物件逃过限额。
- “不问 / 不急 / 不用 / 不必……”这类克制、退让的否定口吻，每人最多三句；同句多个分句也分别检查。事实性否定（没电、没送到、考试没过）与有火气的反驳分开记录。对白包括送礼回应和好感剧情中的引语。泛陪伴型克制声音最多保留给一人；本轮不把它设为任何人的主声线。
- 英语考过、续签、换工、节日等共享主题，都要写进本人生活：杰米的球赛与收音机、阿德的材料夹、莉娜的画稿、普里娅的接待和拼图；不能只对同一句祝贺换几个近义词。
- 盲测每人等量抽句，遮住姓名、ID、声音表与出处后混排；报告种子、逐人结果与作者知情局限。句式统计另做全库审读，不能拿抽样正确率代替。

### 情境与分支

“刚续签”“刚升职”“刚换工”“刚考过”“刚回来”用本季旗标，不能只挂永久经历旗标；季末结束该窗口。钱紧、心情很差直接读当前属性。好感跨档由实际加分记录，日常回应说“最近熟了”，不假定玩家刚完成某个事件。第一年才成立的合租说明挂 `yearMax: 1`；认识已久的说法至少六心，或通过独立的第四年条件实现。

每段好感剧情的两个选择记录各自的分支，后续只说发生过的那个选择。公共回忆仍供原有连锁使用。场景对白先写人物的愿望和分歧，选项决定眼前怎么回应；不把赞同与否当作道德考试。旁白里的时段、天气与地点必须能在原有触发条件或对话发生的位置成立。
